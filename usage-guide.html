话题灵感库使用说明书

1. 这个库是用来做什么的

话题灵感库不是普通备忘录，而是团队的自媒体选题库存。

它的目标是把日常看到的有趣事情、反常识观点、情绪冲突、评论区洞察、热点现象，沉淀成可以被筛选、推进和复盘的爆款选题。

核心流程：

灵感收集 → 选题判断 → 创作推进 → 发布复盘

4. 每天怎么用

每个人每天至少录入 3 条灵感。

不要求一开始就完整，但至少填写：

  • 灵感标题
  • 看到的事情 / 原始素材
  • 内容支柱
  • 创建人
  • 标签

如果已经知道谁推进，就填负责人；不确定就选 未分配。

5. 怎么录入一条好灵感

不要只写一个模糊标题，要尽量保留原始观察。

差的写法：

古代礼仪

好的写法：

今天饭局上大家都在等长辈先动筷子，这让我想到古代“礼”其实不是虚礼，而是一套确认关系顺序的系统。

一条好灵感最好包含：

  • 你在哪里看到的
  • 这件事为什么有意思
  • 它和账号定位有什么关系
  • 观众为什么会点开
  • 有没有冲突、反常识或情绪点

6. 字段怎么填

灵感收集

灵感标题

用一句话概括这个选题。

看到的事情 / 原始素材

记录真实素材，不要过早加工。可以是生活观察、聊天、评论区、书里看到的内容、热点事件。

内容支柱

选择它属于哪个方向：

  • 生活观察
  • 礼乐科普
  • 历史冷知识
  • 文化对比
  • 热点借势
  • 人物故事

来源场景

例如：饭局、聊天、评论区、书、展览、路上、课堂。

素材证据

放出处、链接、截图说明、评论原话、书名、案例。

选题判断

目标受众痛点 / 好奇心

写清楚观众为什么会点开。

一句话选题公式

格式可以参考：

给谁看，用什么冲突/好奇点，讲清什么观点。

例子：

给年轻人讲清楚：饭桌礼仪不是装腔，而是一套古人的社会秩序。

开头钩子

写成视频或图文开头第一句话。

标题候选

每行写一个标题，至少写 3 个方向：

  • 反常识标题
  • 情绪标题
  • 干货标题
  • 悬念标题
  • 热点借势标题

标签

用来后期搜索和归类。

爆款潜力评分

每个维度 1-5 分。

反常识

观众是否会觉得“原来是这样”。

情绪冲突

是否能引发认同、反驳、共鸣、不服、怀旧、震惊。

评论欲望

观众看完是否想表达自己的经历或观点。

转发理由

观众是否有理由转给朋友、同事、家人。

定位匹配

是否符合账号长期方向。

制作难度

越难做分越高，但系统会反向计入爆款分。也就是说，制作越难，综合分会被拉低。

创作推进

流程状态

  • 新灵感：刚记录，还没讨论
  • 待讨论：需要选题会判断
  • 待验证：需要查资料、看数据、找案例
  • 已立项：决定要做
  • 写脚本中：进入脚本阶段
  • 拍摄/制作中：进入制作阶段
  • 已发布：内容已经发出
  • 复盘完成：已经填写结果和结论
  • 放弃：暂时不做

负责人

负责推进这个选题的人。

创建人

发现并录入这个灵感的人。

投票 / 赞同数

选题会或团队内部用来判断优先级。

下一步动作

必须写成具体动作，比如：

  • 查《礼记》出处
  • 找 3 个现代饭局案例
  • 写 60 秒口播脚本
  • 做 5 张图文结构
  • 周会讨论是否做系列

发布复盘

发布后填写：

  • 平台
  • 浏览量
  • 涨粉
  • 复盘结论

复盘结论要回答三个问题：

  1. 为什么成功或失败
  2. 哪个点最有效
  3. 是否值得做成系列

7. 每周选题会怎么用

每周固定开一次选题会。

会议前，每个人先完成：

  • 录入本周灵感
  • 给自己认为值得做的灵感投票
  • 补充标题候选和开头钩子

会议中只看四类：

  • 爆款分高
  • 投票多
  • 优先级高
  • 和账号定位强相关

每次选 3-5 条进入 已立项。

会议结束时，每条已立项选题必须有：

  • 负责人
  • 下一步动作
  • 计划发布平台

8. 团队协作规则

  1. 不要删除别人的灵感，除非已经确认放弃。
  2. 不确定的选题不要删，改成 待验证 或 放弃。
  3. 负责人变更后，要同步更新 下一步动作。
  4. 已发布内容必须复盘。
  5. 好选题可以复制成变体，不要在原选题里混写多个方向。

9. 示例

示例 1

灵感标题：

为什么古人吃饭也要讲礼？

一句话选题公式：

给年轻人讲清楚：饭桌礼仪不是装腔，而是一套古人的社会秩序。

开头钩子：

你以为饭桌礼仪只是客套，其实它曾经决定一个人的社会位置。

示例 2

灵感标题：

现代人为什么越来越受不了仪式感？

一句话选题公式：

给年轻人讲清楚：我们讨厌的不是仪式，而是没有意义的表演。

开头钩子：

我们讨厌的不是仪式感，而是没有意义的表演。

10. 常见问题

打开后没有数据怎么办

先点击 连接云端。

如果仍然没有数据，检查 Supabase URL 和 Publishable key 是否填写正确。

保存后别人看不到怎么办

确认你保存时页面显示的是 已连接云端，不是本地模式。

如果是本地模式，数据只存在你自己的浏览器里。

可以多人同时编辑吗

可以，但当前版本没有冲突提醒。多人同时编辑同一条时，后保存的人会覆盖前面的改动。

Publishable key 能不能发给团队

可以发给内部小团队使用。

但当前版本拿到链接和 key 的人都能新增、编辑、删除数据，所以不要公开传播。

11. 最重要的使用原则

这个库的价值不在于存了多少条，而在于能不能持续筛出值得做的选题。

所以团队要坚持三件事：

  • 每天录入
  • 每周筛选
  • 发布后复盘
